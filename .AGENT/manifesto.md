# PROJECT ATLAS - MANIFESTO

**Il nostro scopo**: Costruire un prodotto con un'anima, non un template.
**Il nostro nemico**: L'AI Slop (elementi generici, gradienti inutili, componenti copia-incolla).

**Le verità che guidano ogni decisione**:
1. Il software deve trasmettere **CALMA**. La preparazione è stressante, l'UI non deve aggiungere rumore.
2. L'utente non deve mai sentirsi **PERSO**. Ogni schermata risponde a UNA sola domanda.
3. L'interfaccia deve essere **INVISIBILE**. Il miglior complimento è "Ho studiato due ore senza accorgermi dell'interfaccia".
4. Il prodotto ha una **PERSONALITÀ**. Se fosse una persona, sarebbe il collega preparato che dice: "Tranquillo. Facciamolo bene."
5. **RITMO**. Come un film, la UI ha momenti veloci, lenti, di silenzio e forti. Non tutto deve urlare.
6. **AUDIO È OPT-IN, MAI DEFAULT**. L'audio (micro-effects, voce del commissario, input vocale) deve rispettare la scelta dell'utente: se l'utente non l'ha attivato esplicitamente, l'interfaccia è silenziosa. Mai un suono automatico, mai una voce che parla senza consenso. L'audio è un valore aggiunto per l'utente "couch persona" (sessioni vocali sul divano con cuffie), non un rumore per la maggioranza. L'app apre in silenzio totale — è l'utente che decide di accenderlo.

**La promessa finale**: Se togli il logo, qualcuno deve riconoscere comunque il nostro stile.
